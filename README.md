# Las flipantes de aventuras del Jorge el dictador

Juego web estático hecho con HTML5, CSS y JavaScript.

## Publicarlo en GitHub Pages

1. Crea un repositorio vacío en GitHub.
2. Sube este proyecto a la rama `main`.
3. En GitHub, abre **Settings → Pages** y selecciona **GitHub Actions** como fuente de publicación.
4. Espera a que termine el flujo **Publicar juego en GitHub Pages** en la pestaña **Actions**.

La dirección pública será `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.
